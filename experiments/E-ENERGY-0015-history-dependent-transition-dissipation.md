# E-ENERGY-0015 — History-Dependent Transition / Dissipation Test

**Date:** 2026-09-04  
**Status:** COMPLETED — PRODUCTIVE / TOY MODEL  
**Parent:** E-ENERGY-0014 / H-ENERGY-05

## Question

Can the smallest history-dependent state make forward and reverse transition costs differ, while keeping the accounting explicit?

## Minimal model

Use the same admissible four-node graph state space as E-ENERGY-0014. Add one internal memory variable `s ≥ 0`.

For an elementary edge transition, define a transition cost

```text
C = 1 + α s
```

where `s` is the current internal memory/strain and `α = 0.5`.

Memory evolves with the transition:

```text
edge added:   s' = s + 1
edge removed: s' = max(0, s - 1)
```

The model therefore has an explicit state

```text
S_eff = (graph, s)
```

and the same graph edit can be traversed in opposite directions at different points in memory state.

## Controlled forward/reverse test

Start with an admissible graph `G0` and `s=0`.

1. Add one legal edge: `G0 → G1`.
2. Reverse the graph edit: `G1 → G0`.

Observed:

```text
forward cost  = 1.0
memory after  = 1.0

reverse cost  = 1.5
memory after  = 0.0
```

Control with `α = 0` gives:

```text
forward = reverse = 1.0
```

Thus the asymmetry disappears when the history term is removed.

## Result

**YES, in the toy model:** adding a minimal history variable is sufficient to make forward and reverse transition costs differ.

But this is **not yet a physical energy result**. The asymmetry is generated by the explicitly chosen state-dependent transition law. We have demonstrated a mechanism for hysteresis-like behavior, not discovered a fundamental energy law.

## Accounting requirement

The transition cost is treated as work exchanged with an explicit reservoir. For each step:

```text
W_in - W_out = ΔU_internal + E_rejected
```

No conservation claim is made unless all three terms are explicitly measured/defined for the complete model boundary.

## Falsification boundary

The experiment does NOT establish:

- that memory is required for physical energy;
- that `C` is physical work;
- that hysteresis is a universal source of energy;
- that the model generates energy.

It establishes only that:

> A history-dependent state can create directional transition costs even when the underlying graph edit itself is reversible.

## Next decisive step

Replace the abstract cost `C` with a measurable physical quantity in a controlled converter. Candidate systems include a mechanical spring/damper, electrical RC/RL hysteresis-like system, or magnetic actuator. The physical experiment must independently measure input energy, useful output, internal-state change and rejected energy.
