# Native experiments

This directory contains experiments designed specifically for `energy-conversion`.

- `EXP-0001-energy-accounting-and-conversion-graph.md` — foundation for measurable conversion and closed accounting.
- `E-ENERGY-0014-transition-cost-from-state.md` — exhaustive finite-state test; reversible structure alone does not generate energetic directionality.
- `E-ENERGY-0015-history-dependent-transition-dissipation.md` — toy test showing that an explicit history variable can create directional transition costs; not a physical energy result.

Legacy Ω-Lab experiments are under `legacy/omega-energy/` and remain provenance material rather than established physical theory.
