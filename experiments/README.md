# Native experiments

This directory contains experiments designed specifically for `energy-conversion`.

## Canonical records

- `EXP-0001-energy-accounting-and-conversion-graph.md` — foundation for measurable conversion and closed accounting.
- `E-ENERGY-0014-transition-cost-from-state.md` — exhaustive finite-state test; reversible structure alone does not generate intrinsic temporal directionality.
- `E-ENERGY-0015-history-dependent-transition-dissipation.md` — toy mechanism-isolation test showing that an explicit history variable can create history-dependent transition costs; not a physical energy result.

The former duplicate `E-ENERGY-0015-history-dependent-transition-dissipation-test.md` has been removed. `experiments/EXP-0001/README.md` is retained only as a compatibility pointer to the canonical EXP-0001 record.

## Reproducibility

- `code/e_energy_0014_repro.py` reproduces the finite-state enumeration and key invariants of E-ENERGY-0014.

## Research boundary

Legacy Ω-Lab experiments are under `legacy/omega-energy/` and remain provenance/hypothesis material rather than established physical theory.

The next decisive branch is physical: map measurable difference + physical coupling to measurable energy transfer with a closed, independently checked account.
