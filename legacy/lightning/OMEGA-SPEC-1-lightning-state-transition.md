# Ω-SPEC-1 — Спектральная последовательность молниевого разряда

**Date:** 2026-08-14  
**Status:** observation / working hypothesis  
**Type:** external physical analogue for testing the language of states and relations  
**Important:** not an Ω derivation.

## Core observation

Lightning creates a high-energy plasma channel. Excitation and ionization are followed by recombination and relaxation; chemical processes occur in parallel. Spectral lines are treated as observable traces of particular excitation/ionization states, not as causes of chemical formation.

## Temporal structure

Working sequence:

**early:** strong ionization / ionic lines  
↓  
**transition:** ionic lines decrease, neutral components increase  
↓  
**late:** neutral atoms and subsequent relaxation/cooling

## Relational representation

Nodes:

- E — high discharge energy;
- I — ionized state;
- T — transition state;
- N — neutral state;
- C — chemical restructuring;
- R — relaxation/cooling;
- S — observable spectral signal.

Working relations:

`E → I → T → N → C/R`

with `I/T/N → S` as the observation channel.

## Ω question

> Can the sequence of observable spectral states be used to reconstruct the sequence of system transitions?

More minimally:

> Is distinction between states a sufficient observable sign of a relation between them?

## Boundary

This file does **not** claim that color is a fundamental entity, that ozone corresponds to a particular color, or that the graph is a fundamental description of lightning. It is physical motivation for testing the state-transition language.

## Working formula

`state → distinction → transition → new state → observable trace`
