## Lightning / electromagnetic branch

- `Ω-SPEC-1 — Спектральная последовательность молниевого разряда`
- `E-MAGNETIC-0001 — Environmental Potential, Magnetic Loop and Lightning Analog`

The lightning work is treated as an external physical analogue and an engineering test target, not as proof of the Ω model.

## Core structural conclusions carried forward

1. A static relational structure can have different future transformation capacity under a defined rewrite system.
2. Conservation and a transition barrier can coexist; neither alone produces energetic release.
3. Directionality does not arise merely by naming states or inserting an ordering relation.
4. Local apparent release can be redistribution of a conserved quantity into another degree of freedom.
5. Finite resource + competing relations + positive feedback can produce channel selection.
6. Adding memory can make the selected structure persistent/reusable in the toy model.
7. Spatial implementation reproduces qualitative channelization, but this remains a toy relational model.
8. Reproducibility is a separate status: E-ENERGY-0032R did not reproduce all exact numerical values of E-ENERGY-0032.
9. Three-state/color language is an operational encoding unless the states emerge from dynamics.
10. None of these experiments by themselves establishes a new physical definition of energy or a causal theory of lightning.

## Provenance rule

For every migrated experiment retain:

`ID → date → parent → question → model → controls → result → negative result → limitation → next experiment → original Ω-Lab path`

**UNKNOWN ≠ TRUE. Hypothesis ≠ Result. Calculation ≠ Experiment.**
